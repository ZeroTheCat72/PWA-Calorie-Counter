# PWA Calorie Counter
PWA Calorie Counter is a free, open source web app that gets a Nutrition List for all foods you can think of; You can install it on iOS via Safari -> share -> add to home screen, similiarly on Android (Chrome).
Microsoft Edge prompts you to do so, and I think Google chrome does it too.

## How to use?
The way this app functions is you get an API key from the USDA Food data central website and input it inside the app, since Im using their API.
However, since the app is still in beta, Only people in the beta can use my own API key.

## With that said:
If you want to get your own API key for evermore use, go to https://fdc.nal.usda.gov/api-key-signup and you should get an email for the API key.
